# Rule: Ralph Loop - Relentless Iterative Verification

## Directives
1. **Verification Loop**: Before declaring any task complete, perform an end-to-end verification:
   - TypeScript compilation check (`npm run build`).
   - Visual inspection against target reference layouts.
   - Interactive flow verification (navigation, modals, forms, tabs).
2. **Error Immunity**: If any tool, image generation, or network call fails, immediately fall back to a high-fidelity local programmatic alternative (e.g., SVG/Canvas 3D isometric city rendering, reliable asset pipelines) so the user never receives broken layouts.
3. **Continuous Polish**: Verify typography, spacing, border radiuses, contrast ratios, and tabular fonts across all breakpoints.
