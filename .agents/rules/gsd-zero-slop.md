# Rule: GSD (Get Shit Done) - Zero AI Slop Protocol

## Directives
1. **Zero Placeholders**: Never write `// TODO`, `// Add logic here`, or stub functions. Every screen, form, button, and interaction must be 100% functionally complete.
2. **Exhaustive Scope Completion**: Implement all 15 screens shown in the design specification completely.
3. **No Compromises**: All tabs, filters, sliders, modals, state toggles, and charts must be fully interactive and responsive.
4. **Data Integrity**: Provide realistic, high-fidelity mock data and backend fallbacks matching the exact metrics in the CivicCare institutional specification (12,480 reports, 8,932 resolved, 3,121 in progress, 98% on-time).
