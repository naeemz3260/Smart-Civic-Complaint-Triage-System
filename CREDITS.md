# Credits & Acknowledgements

The **Smart Civic Complaint Triage System** is built on the shoulders of the open-source civic technology community. We gratefully acknowledge:

- **OpenStreetMap & CartoDB**: Geospatial foundations, coordinate projections, and open tile layers for civic mapping.
- **FastAPI & Pydantic**: Ultra-fast, type-safe Python asynchronous web framework enabling responsive municipal APIs.
- **Scikit-Learn**: Robust machine learning utilities powering TF-IDF text categorization and classification metrics.
- **Vite & React**: Lightning-fast web application build tooling and responsive interface rendering.
- **Lucide Icons**: Beautiful, consistent iconography representing civic services and status indicators.
- **Local Municipal Innovators**: Civic volunteers, municipal sanitation workers, and city engineers whose real-world triage constraints inspired our four-factor priority engine.
